# RACOMA animation prototype

Open `versions.html` to choose between four animation themes:

- A: Soft emergence
- B: Editorial reveal
- C: Slow breathing
- D: Spatial layers

`index.html` preserves the original layout. All five pages share the five-second
hero carousel and its countdown progress bar. Images, fonts, and logos are local
under `assets/`.

No build or dependency installation is needed to view the prototype. Download
or clone the full repository, then open `versions.html` in a browser.

See `MOTION.md` for mixing animation themes by region. Verification scripts use
the original development machine's local Playwright and Edge paths; adjust those
paths before running them on another computer.
